# Z80 Print Example

## 概要

このプロジェクトはC言語で書かれたZ80向けのプログラムをビルドするためのサンプルです。

ターゲットはSuper AKI-80を想定しています。

UARTで簡単な文字列を出力する例を実装しています。

- CTC/SIOの初期化を行う
- `SIOA`を使って文字列を出力する
- 16進数の値を順に表示する
- `make`で`.bin`/`.ihx`/`.dis`/`.h`を生成する

## ディレクトリ構成

```text
.
├── crt0.s              # ブートストラップ
├── Inc/                # ヘッダーファイル
│   └── ...
├── Src/                # ソースコード
│   ├── main.c
│   └── ...
├── build/              # ビルド成果物
│   ├── *.bin           # 生成されたバイナリ
│   ├── *.ihx           # Intel HEX形式
│   ├── *.h             # バイナリを配列化したCヘッダ
│   ├── *.dis           # 逆アセンブル結果
│   └── ...
├── Makefile            # ビルド定義
├── README.md           # このファイル
└── ...
```

## 環境構築

```bash
sudo apt update
sudo apt install -y make sdcc xxd z80dasm
```

## ビルドとクリーンアップ

リポジトリのルートで以下のコマンドを実行してください。

```bash
# プログラムをビルドし、生成物を build/ 以下に出力する
make

# build/ 以下の成果物を削除する
make clean
```

## メモリ配置

Super AKI-80 のメモリマップに準拠したアドレス設定を採用しています。

| 範囲 | 種別 | 用途 |
| --- | --- | --- |
| `0x0000` 〜 `0x01FF` | ROM | ブート領域 |
| `0x0200` 〜 `0x7FFF` | ROM | プログラム本体の配置領域 |
| `0x8000` 〜 `0xFFFF` | RAM | グローバル変数、データ領域、スタック |
